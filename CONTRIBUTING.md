# Contributing

## Branching
- Use short-lived branches off `main`.
- Suggested naming: `feat/<topic>`, `fix/<topic>`, `chore/<topic>`.

## PR checklist
- Linked issue/work item
- Tests added/updated (as applicable)
- Security considerations noted (auth, data access, secrets)
- DB changes documented (migrations/scripts)

## Definition of Done (DoD)
- PR merged to `main`
- Build is green
- Feature has acceptance criteria and is verified
- Docs updated if behavior or APIs changed
