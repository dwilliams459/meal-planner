# ADR: Record Architecture Decisions

- Status: Accepted
- Date: 2026-02-10

## Context
We need a lightweight way to capture decisions (tech, patterns, tradeoffs) as the project evolves.

## Decision
Use ADRs in `docs/adr/` with a simple template and sequential numbering.

## Consequences
- Decisions are discoverable and reviewable in PRs.
- We can revise by creating new ADRs that supersede older ones.
